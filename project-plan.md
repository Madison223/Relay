Project: Real-Time Chat Web App - Relay


Purpose: To learn and demonstrate React, Node.js, PostgreSQL, and real-time communication.


- User can sign in with Google
- User can create a chat room
- User can see available chat rooms
- User can enter any public chat room
- user can send text messages
- Other users in the room can recieve messages without refreshing
- previous messages remain after refreshing
- creator can delete chat room


User flow:

- Visit Site -> Sign in with Google -> See chat rooms -> Join room -> Read messages -> Send message

- Chat rooms -> Create room -> Enter name -> public -> Create -> Room appears -> Enter Room
